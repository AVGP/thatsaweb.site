Dear diary,

today I got a computer! My own computer, can you believe it? It's like the C16 but it can do more stuff and quicker!
I'm super excited about the games, but I'm also super excited about something else.

Remember when I read the manual of the Commodore and found out I can make my own programs? I'm sure this also works here, I just have to find out how.
I think there's BASIC for Windows 98, but I haven't found it in the menu yet. The manual also doesn't say anything about it, weird.

I'm super excited though - graphics are probably much cooler here and maybe I can write programs that can do more and are larger than what I've done so far.
I'll check the library to see if they have books on how to program this computer. Maybe I can even write graphical programs with windows and stuff - SO EXCITING!

I only have a few hours each day, but I'll do my best to get my homework done (if only I already knew how to write programs for this thing, it would make homework FASTER) quickly and then figure this thing out.
My friends in school were mostly excited about the games we can play on it, but I wanna make my own games!

Maybe that's a job? Maybe I can make money making games! I think I'll make a website for my games and figure out how to sell them there, too.
But first I need to work out how to build programs for this. What an exciting day!

Well, time do do my homework and then off to the library - I bet I can write programs for this :)

I wonder if one day my job is going to be making programs for people - that'd be cool, I think.
