Holy vaporwave, Batman! It's a website.
Yeah, just some random website on the internet - like it used to be, like it (hopefully) always will be.
Made from markdown files, pushed to Github, hosted on render. The only thing that costs some money in this whole setup is the domain name.

I miss the days we all just mixed HTML, maybe some CSS and perhaps a sprinkle of JavaScript together for a random, whimsical page that lived on the web.

But I'm not just complaining like the generic old bloke from another era - so I made this thing. And I love it.
I'll periodically post random stuff here. Things I think about, things I found somewhere on the web, you know, like in the olden days.

Let's see where it leads us :)
